Requisitos
1 - Criar um h1 com o nome da dupla
2 - Criar um array (criado dentro da App.jsx) com no mínimo 5 objetos.
3 - Cada objeto deve ter:
      Pelo menos 5 atributos mais um chamado "status" onde deve possuir um valor (true ou false)
4 - Exibir todos usando map().
5 - Criar um componente Card.
6 - Enviar os dados por props.
7 - Fazer renderização condicional:
      Se status = true → "Disponível"
      Se status = false → "Indisponível"
8 - Criar um useState para alterar o título da página.


Entrega: arquivo .rar ou .zip anexado aqui.
